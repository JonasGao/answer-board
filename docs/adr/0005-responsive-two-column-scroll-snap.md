# 响应式两栏与逐屏滚动问题流

问答页的单栏长文档在滚动后看不到标题、背景事实和默认项；连续排列所有问题也缺少明确的当前位置。维护者于 2026-11-12 从三个浏览器原型中选择 B 方案的粘性参考栏，并要求引入 C 方案的逐题节奏和顶部进度条。

决定：

- 宽屏（≥1024px）采用左侧参考信息、右侧问题流的两栏布局。左栏使用 `position: sticky`，内容超过视口时仅在左栏内部滚动；右侧保持连续文档，所有问题仍在同一个表单中。
- 每道题以及「总备注 + 提交」分别构成一个滚动面板，最小高度为视口减去顶部进度条。宽屏在根滚动容器使用 `scroll-snap-type: y proximity` 和 `scroll-snap-stop: always`，通过滚动切题；长问题自然增高，不使用可能遮住长内容的强制吸附。
- 双向导航采用维护者选定的 A 方案：题底「返回上一题 / 滚动到下一题」锚点链接并排居右，第一题仅显示下一题，总备注可返回最后一题。继续使用同一文档与原生锚点，不引入单题渲染或额外路由状态。
- `↑` / `↓` 在非输入控件聚焦时切换上一屏或下一屏，每次按键只切一屏，长按不连续跳题，首尾不循环；文本框、选择控件和滑块等输入控件保留原生方向键行为。
- 顶部工具条也是页首吸附点，使首次加载停留在 `scrollY = 0`，不会自动卷走宽度和字号设置。工具条本身仍不 sticky，延续 ADR-0004。
- 右栏顶部的进度条表示当前位置而非已答数量；左侧问题索引与滚动位置同步，可直接跳题。必答题漏答时，提交会滚动并聚焦第一道漏答题。
- 窄屏堆叠为参考信息在上、问题在下的单栏，保留逐屏最小高度，但关闭滚动吸附，避免长参考区与吸附争用滚动位置。
- `--page-width` 表示整体页面宽度，默认 1440px，服务端将 round JSON 的 `width` 夹到 1000–4000px。显示偏好改用 `answer-board:pageWidth`，避免旧单栏保存的 820px 偏好压缩两栏布局；字号偏好键不变。

被否方案：

- **A：左右栏都固定并独立滚动**：滚动容器和进度同步更复杂，也放弃了已选 B 方案的单文档阅读方式。
- **C：每次只渲染一道题**：需要额外的上一题/下一题状态管理，无法仅靠原生滚动和锚点完成导航。
- **全屏 mandatory 吸附**：对超长问题不友好，可能让面板首尾之间难以阅读；`proximity` 保留逐屏节奏并允许自然滚动。

验证：使用真实 `board.mjs` 在 1440×900 和 390×844 视口检查两栏、窄屏、滚动吸附、进度同步、表格溢出和漏答回跳；完成一次真实提交并核对答案 JSON，服务正常退出。双向导航落地后，再次验证题底链接、Q1 上边界、方向键逐屏切换、文本框与单选控件原生方向键、总备注往返和 390×844 窄屏同排布局；真实提交保持答案结构不变，服务以退出码 0 结束。

本决定修订 ADR-0003 中默认宽度、宽度下限和偏好键的对应部分；Markdown 表格滚动与 ADR-0004 的字号体系保持不变。
