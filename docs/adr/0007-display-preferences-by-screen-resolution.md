# 按屏幕分辨率在服务端保存显示偏好

同时运行的答题板会使用不同端口，浏览器按访问来源隔离宽度和字号。改为由服务端在 `$XDG_CONFIG_HOME/answer-board/display/` 下保存显示偏好，默认使用 `~/.config/answer-board/display/`。

以浏览器报告的逻辑屏幕宽高为键，格式为 `宽x高`。同一台服务机器上的各个答题板端口和等分辨率设备共享一组设置。窗口缩小时只限制实际显示宽度，保留原偏好值。字号与宽度分别原子写入文件，让同时运行的服务可以独立修改不同设置。

页面初始化时读取当前分辨率。服务端没有对应设置时，可将当前访问来源的旧浏览器设置导入。同一分辨率上点击「标准」会清除对应覆盖值，保留已重置状态以避免再次导入旧值。
