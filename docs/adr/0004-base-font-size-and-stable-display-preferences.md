# 全页基础字号与稳定 origin 显示偏好

问答页需要同时调整文档和表单界面的阅读字号，并让宽度、字号偏好在刷新和后续轮次中可用。决定以根元素的 `--font-size-base`（默认 16px）为唯一字号基准，所有 `font-size` 使用 rem；顶部滑块允许 14–28px，文档 h1–h4 在默认字号下分别为 24、20、18、16px，其余文字保持原有相对比例。成功页继承当前根字号，不重复提供工具条。

工具条仍在文档顶部，但不再 sticky；窄屏通过换行保留宽度与字号控制。`ask.mjs` 从 19876 起递增选择空闲端口，取代随机端口，使同一 origin 下的 `localStorage` 偏好跨轮、跨项目保留。不同主机或端口仍各自隔离；不新增 round JSON 的字号字段。

## Considered Options

- **基础 px 变量配合 `calc()` 比例**：能保留默认视觉，但每处都显式写计算式；选择根字号 + rem，让统一缩放成为样式的固有结构。
- **继续随机端口、按轮隔离偏好**：隔离更强，但无法满足稳定保留设置的需求；接受同 origin 跨项目共享作为明确的产品语义。
- **sticky 工具条或窄屏隐藏**：会持续占用视口或使手机无法调字号；改为普通文档流和窄屏换行。

以上决策由维护者于 2026-11-07 经 answer board 多轮确认；它修订 ADR-0003 中随机端口、sticky 工具条和窄屏隐藏工具条的旧决定。
